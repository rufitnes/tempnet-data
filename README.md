# tempnet-data
Live telemetry from the BCH tempnet (faster-blocks testnet for the 2027 chipnet upgrade): block intervals, 10-block windows, MTP lag, orphans/reorgs and local receive times. Updated every 10 blocks or 15 min. Companion dataset to the tempnet thread on bitcoincashresearch.org https://rufitnes.github.io/tempnet-data/
